What this is not

  • Not a pipeline

    There are no stages, no next actions, no 'touches'. Career work is not outbound.

  • Not a manager spyglass

    The Structural Fold pack is a tease, not a checkout. This map is for ICs walking their own building.

  • Not a blank canvas

    Import a CSV, filter same-company versus personal, then name people in three taps. The map is built, not drawn.
